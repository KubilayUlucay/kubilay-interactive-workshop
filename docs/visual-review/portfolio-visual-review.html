How this was checked

These are browser-rendered 3D screenshots, produced in hosted Chromium with SwiftShader. The source commit was checked against the Site’s saved version 1. The test browser could not access the live URL directly, so a review build imported that published source.

The review bridge exposes the existing renderer and production simulation. Keyboard and touch controls set the hold state; the simulation is then advanced to repeatable endpoints. Stills use the settled camera and refreshed shadows. Geometry, materials, lighting and page CSS were retained. The same named fonts were supplied locally from Fontsource packages.

Both viewports created WebGL2 contexts, displayed their fonts and had no horizontal document overflow. The motor itself is still visually cropped on mobile. These stills establish appearance, not hardware FPS or the quality of the complete animated transition. Crank picking, orbit gestures and real-device performance require separate checks.
